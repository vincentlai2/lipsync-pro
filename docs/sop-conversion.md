# SOP (标准作业程序)：AI SaaS 落地页设计与转化率优化 (CRO) 指南

本内部参考文档总结了将技术导向型开源项目转化为**高转化率 (CRO) 和搜索引擎优化 (SEO) 商业 SaaS 网站**的开发方法论、页面架构设计和文案撰写规范。

---

## 1. 核心理念：从“技术描述”到“商业变现”

*   **黄金法则**：不要兜售底层技术细节（*在底层是如何运作的*），而要展示**核心利益**（*这能为用户的钱包节省多少钱，为他们的工作流省去多少时间*）。
*   **文案表达规范**：
    *   *❌ 避免使用（开发视角）*：”我们的模型基于 SyncNet 和 GAN 架构，支持无 Python、无 Colab 部署，可在 GPU 节点上计算人脸坐标。“
    *   *✔️ 推荐使用（商业视角）*：”无需重新录制，一键完成多国语言视频的对口型配音与翻译。100% 在线操作，无需安装任何软件或配置底层环境。“

---

## 2. SEO SOP：关键词布局与多语言本地化

1.  **H1 核心词绝对匹配**：
    *   每个落地页的单个 `<h1>` 标签必须包含主品牌词与用户核心检索词（例如 `Wav2Lip IA` 或 `Wav2Lip en ligne`）。
    *   *H1 优化示例*：`Synchronisez vos vidéos avec Wav2Lip IA en 1 clic`（一键使用 Wav2Lip IA 调整您的视频嘴型）。
2.  **顶部引导小徽章 (Badging LSI)**：
    *   在 H1 上方放置一个极富科技感的小徽章标签，用来融入高频的长尾关联词（如：免费、在线），同时加入评分等社交信任背书。
    *   *示例*：`★ 4.9/5 | +10K créateurs font confiance à Wav2Lip IA en ligne gratuit`（★ 4.9/5 | 超过一万名创作者信赖的在线免费 Wav2Lip IA 嘴型对齐工具）。
3.  **严格的本地化语言一致性**：
    *   检查并确保所有页面文案、用户评价（Testimonials）和模拟使用场景中的国家和语言指代，与当前站点的目标市场 100% 保持一致（例如，在法语站中，应指代“法语频道”或“法语配音”，避免出现其他语言指代造成用户困惑）。

## 3. CRO SOP：黄金转化漏斗（首页页面架构规范）

首页布局应遵循以下用户心理决策流程进行排布：

1.  **首屏 Hero 区**：
    *   **布局要素**：痛点清晰的价值主张 + 双 CTA 按钮（明亮的主色按钮引导“免费测试”，幽灵按钮引导“查看价格/教程”）+ **真实的交互式视频对比播放器（Before/After）**。
    *   *逻辑*：直接用真实人脸对比视频证明效果，打消用户对 AI 拟真度的怀疑，引导点击转换。
2.  **极简 3 步工作流 (Workflow)**：
    *   紧贴 Hero 屏下方，展示“1. 上传视频 ➔ 2. 导入配音 ➔ 3. 一键下载”。
    *   *逻辑*：极力降低认知门槛，暗示用户无需任何 Python 或复杂技术储备即可上手。
3.  **功能与应用展示 (Bento Grid 块)**：
    *   采用现代 Bento Grid 网格布局，右侧或下方不放置静态无聊的图标，而是放置**带静音自播的短视频循环**或**本地虚拟人主播头像矩阵**。
    *   *逻辑*：让页面“动起来”，展示 YouTube 配音、TikTok 短视频等具体商业落地情景，增加高级感。
4.  **竞品对比矩阵表 (Comparison Matrix)**：
    *   *⚠️ 核心红线*：**绝不在表格中提及竞争对手的真实域名或名字**，避免将自家流量无偿引导至竞对网站。一律使用通用指代名词（例如：*“其他在线工具”*、*“开源 Colab / 源代码”*）。
    *   突出自身独占卖点：渲染速度（H100 算力）、文件绝对私有化、失败额度自动返还。
5.  **零风险退款承诺 (Risk-Reversal)**：
    *   明确提示：如遇人脸识别失败或渲染出错，系统会**自动 100% 退回扣除的积分额度**，打消付费体验的后顾之忧。
    *   *逻辑*：通过极度坦诚的退额度机制建立起坚实的初次信任。
6.  **本土化社交证明 (Testimonials)**：
    *   提供与配音、翻译、视频剪辑效率提升高度相关的真实场景评价，人名和头像均进行本地化适配。
7.  **阶梯式价格卡片 & 常见问题 (FAQ)**：
    *   展示清晰的单币价格梯队，对“最畅销（Most Popular）”档位应用霓虹悬停发光边框以凸显核心转化目标。

## 4. UI/UX SOP：现代 SaaS 的高级质感与微动效

1.  **暗色深邃背景与毛玻璃微框**：
    *   统一采用极具科技感的暗色系背景（`bg-black` / `bg-zinc-950`）。
    *   板块之间不使用生硬的粗线分割，使用毛玻璃和极细透光描边（`border-white/10 bg-black/40 backdrop-blur-md`）。
    *   利用绝对定位的径向渐变大滤镜在后台布置冷光背景光源（`bg-primary/5 rounded-full blur-3xl -z-10`）。
2.  **精致微交互动效**：
    *   为所有卡片和交互按钮设置平滑的缩放和色彩悬停响应（`hover:scale-[1.02] transition-transform duration-300`）。
    *   关键板块上增加微妙状态动效（如：TikTok 音乐光盘自转动效、表示同步处理中的绿色微光呼吸灯）。

## 5. 开发规范与 Linter 编译 SOP

1.  **“延迟校验”与未登录状态下的 SEO 聚合页**：
    *   **统一入口 URL**：在线生成页（如 `/wav2lip-en-ligne` 或 `/studio`）在未登录和已登录状态下使用统一入口，避免未登录直接硬重定向到登录页。
    *   **双态展示逻辑**：
        *   *已登录状态*：展示纯净、高效的 SaaS 后台操作区（Studio 工作空间），隐藏冗余的 SEO 说明文案，提供专业、专注的视频处理环境。
        *   *未登录状态*：操作区保持可见，允许游客在本地拖拽、选择并预览视频和音轨。同时，在**操作区正下方布置完整的 SEO 长文案与外链**（如详细视频教程、FAQ 常见问题解答、价格对比矩阵等），以此满足 Google 收录对高频 URL 页面文字内容丰富度的要求。
    *   **无感登录拦截**：仅在游客最后一步点击“生成（Générer）”准备占用服务器 GPU 计算资源时，才以模态框（Modal）形式唤起 Better-Auth 登录。登录完成后，非刷新式更新 session，必须完美保留本地已选择的媒体文件状态，无缝进入下一步，避免刷新导致重新选择。
    *   **微动效增效**：生成成功时，必须触发全屏五彩纸屑洒花动效（`canvas-confetti`）以带给用户极强的收获感。
2.  **无感就地充值与动态支付回调（In-page Modal-based Recharge）**：
    *   **避免素材状态丢失**：当用户在 Studio 界面中积分不足（Insufficient Credits）或者在控制台卡片中点击“充值/Recharger”时，**严禁重定向或跳转到独立的 `/pricing` 路由页面**。因为这会导致用户已经拖拽并上传完毕的音视频客户端 State 被彻底擦除。
    *   **就地弹窗机制**：必须就地拉起 `PricingModal` 弹窗展示价格卡片。这能确保用户付费充值完成后，关闭弹窗即可直接点击“生成”按钮，完全保留所有已上传文件状态。
    *   **Stripe 动态回调支持**：在创建 Stripe Checkout Session 接口中接收并支持 `successCallbackUrl` 与 `cancelCallbackUrl` 参数。若从 Studio 面板发起充值，支付成功后自动将其引导重定向回原页面（如 `/wav2lip-en-ligne`），提供无缝的闭环体验。
3.  **规范压制 Biome 编译报错**：
    *   在 HTML5 视频展示元素中，若无 caption track，为避免代码规范工具报错阻塞流水线，应在对应位置严格使用精准的 suppression 注释：
    ```tsx
    {/* biome-ignore lint/a11y/useMediaCaption: demo video does not require captions */}
    <video src="..." />
    ```
4.  **上线前双重检查指令**：
    *   每次修改代码并推送前，依次在终端运行以下命令验证健康度：
    *   `pnpm lint`：确保无任何代码规范报错。
    *   `pnpm build`：确保生产环境能够顺利通过服务端渲染（SSR）和 TypeScript 静态检查。
